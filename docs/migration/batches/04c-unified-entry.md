# 04c — единый вход и регистрация

Решение пользователя 6 ноября 2026: одобрена схема контакт → OTP → существующий аккаунт либо оформление нового. Это согласованное изменение порядка A1/A2/A3, а не буквальная копия старого прототипа. Только локальная реализация, обе темы и RU/EN; без commit/push.

## Результат и границы

Одна точка входа, заранее объясняющая регистрацию нового пользователя. После кода существующий аккаунт открывается со своими данными и ограничениями. Новый подтверждённый контакт ведёт к выбору личного/бизнес-профиля и обязательным полям. Незавершённый профиль восстанавливается после повторного подтверждения того же контакта. Телефон и почта не объединяются автоматически. Вход через другой контакт и восстановление остаются доступны.

Подтверждение контакта не равно KYC/KYB. Новый профиль имеет нулевые балансы, пустую историю и ограничения. Недоступность реестра не считается отсутствием аккаунта. Локальные хранилища и код 123456 — имитация, не серверная аутентификация.

## Матрица обязательных веток

| Случай | Ожидаемый результат |
|---|---|
| Новый контакт, верный OTP | Профиль; до сохранения нет обычного сеанса кошелька |
| Существующий контакт | Его Home; нет повторной анкеты или fixture-данных |
| Неверный/истёкший OTP, resend | Ошибка/новый код; нет создания аккаунта |
| Пустые данные, business без реквизитов | Ошибка у формы, сохранение введённых данных |
| Профиль после reload | В пределах подтверждения продолжается; после истечения нужен OTP |
| Другой контакт / выход / recovery | Старое подтверждение недействительно; нет чужого черновика |
| Повторная отправка/запоздалый ответ | Нет дубликата, возврата в отменённый флоу или ложного успеха |
| Сбой/повреждение хранилища | Доступ не выдан; повторная попытка, не новая регистрация по ошибке |
| Прямой register/home URL | Не обходит подтверждение/заполнение профиля в auth-режиме |
| Новый аккаунт / повторный вход | Нулевые балансы, правильный владелец, ограничения сохранены |
