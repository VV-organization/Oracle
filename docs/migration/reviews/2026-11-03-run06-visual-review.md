## Окончательная область и ограничения

Независимо просмотрены **все36 снимков run06**, сопоставлены с36 записями actions.json. Непринятых промежуточных кадров в этом проходе по наблюдаемым снимкам/журналу не выделено.01 и21 — служебныеRestart; сегменты01–20 и21–36 разделены, поэтому две OP-IN-002 нельзя считать параллельными независимыми операциями одного сеанса.

Во втором сегменте инструкция содержит номер карты и не зачисляет деньги сама. Поддержка проверена без отправки; clipboard — только по видимой подписи. B00-021 иB00-022 воспроизводятся для перевода по номеру карты. B00-015 виден в18/20, но не в34/36.

Внешняя оплата,3DS, списание, реальный перевод по номеру карты, произвольная сумма, провайдерские ошибки, мобильный вид, полный фокус и серверная идемпотентность остаются непроверенными. Это принятие сохранённых визуальных наблюдений, не всего карточного семейства, frontend или пакета00.
