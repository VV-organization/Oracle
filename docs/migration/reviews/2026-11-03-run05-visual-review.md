## Выявленные расхождения и ограничения

1. **Старое подтверждение копирования сохраняется при новом открытии.** В18 оно появляется после действия копирования; диалог закрыт19, затем выполнены переходы20–23. В24 надпись уже видна при повторном открытии инструкции из операции. Снимки подтверждают сохранение обратной связи через этот маршрут, но не определяют причину в коде и не доказывают новое копирование.
2. **Единственный банковский метод оформлен как выбор.** В07 (USD/Германия) и12 (EUR/Швейцария) SWIFT — единственная показанная строка, но содержит radio, рамку и выбранную обводку. Это расходится с правилом проекта показывать один фиксированный метод простой строкой детали. Работоспособность клика по этой строке не оценивалась.
3. OP-IN-002 согласован между главной, историей, деталями и инструкцией по видимым суммам и состоянию ожидания. Баланс EUR не увеличился. В22 видна одна строка OP-IN-002; после повтора27–30 тоже показана одна строка с тем же идентификатором. Это ограниченное наблюдение одного повтора, не проверка серверной идемпотентности.
4. Контекст закрытия инструкции сохранён в19; возврат в каталог виден20. Возврат из деталей в историю с исходными общими фильтрами виден30. Сохранение изменённых фильтров, статусный переход и чистый повтор после Restart в01–30 не покрыты.
5. Нет доказательств произвольного ввода суммы, ошибок, клавиатуры/фокуса, мобильного вида, реального банковского перевода или подтверждения платёжного сервиса. Даты являются видимыми данными прототипа; их связь с реальным временем не проверялась.

Проверка этой части завершена только в пределах перечисленных снимков. Приёмка всего пакета00 и реализация frontend не заявляются.
