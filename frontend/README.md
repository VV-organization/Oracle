# OraclePay frontend

Поддерживаются только зелёная версия с карточками и оранжевая со счетами слева. Готовые отдельные сборки: `../Oracle/green` и `../Oracle/orange`. Пересборка — `npm run build:variants`. Актуальная визуальная спецификация — [WALLET-HOME-2026-11-05.md](WALLET-HOME-2026-11-05.md); нейтральные размеры ниже относятся к историческому переносу Figma.

Локальный перенос главной и диалогов реквизитов на React + TypeScript. Нужен Node.js 24.

```sh
npm ci
npm run dev
```

- Вариант 1, компактные карточки `2723:1823`: http://127.0.0.1:5173/?layout=cards
- Вариант 2, счета слева `2716:872`: http://127.0.0.1:5173/?layout=columns
- Историческая композиция D1 для сверки: `?layout=baseline`
- Два цветовых превью: `?layout=cards&theme=green` и `?layout=columns&theme=orange`. Перекрёстные цветовые URL приводятся к этим парам. Без параметра сохраняется нейтральная версия. Палитра пока не выбрана; токены и референсы — в [DESIGN.md](DESIGN.md).
- Рабочие каталоги: `&lang=ru` / `&lang=en`. Выбор языка сохраняется; переключатель находится в боковом меню. Перевод EN ещё не утверждён.

`npm run build` проверяет TypeScript и собирает приложение; `npm test` проверяет точное представление денег, выбор/фильтрацию счетов и состав копируемых реквизитов.

Реализованы композиции, данные девяти счетов, 20 операций (четыре исходные и 16 вымышленных по просьбе пользователя), выбор/снятие выбора, фильтрация и пустая история CHF. На Главной показываются до четырёх последних операций после фильтрации. Исходные четыре записи сохранены отдельно для исторической композиции. Данные приходят через `DashboardService`; локальный mock не подключает финансовые сервисы. Денежные значения хранятся как строки минимальных единиц без float-арифметики.

Подключены все девять контекстов реквизитов/адресов: EUR, USD domestic, GBP/CHF без доступных реквизитов, пять криптоактивов с XRP tag. Общий диалог сохраняет фильтр истории, закрывается крестиком/Escape, удерживает и возвращает фокус; фон не закрывает его. Копирование работает через Clipboard API, подтверждение появляется после успешной записи. Банковская кнопка копирует все шесть подписанных строк, отдельные кнопки — номер счёта/IBAN и банковский код. Криптокнопка копирует адрес; XRP tag остаётся отдельным текстом, как в источнике.

Финансовые действия, отдельная история, детали операций, помощь, настройки и выход пока не подключены. При нажатии появляется временное сообщение о границе текущей сборки; это не продуктовый экран и не реализованный переход. Цветные варианты главной и диалог адаптированы к узкому окну; на мобильном обе версии используют карточки и раскрываемое меню.

Пользователь подтвердил фильтрацию по счёту и добавление вымышленных операций: начальный USDC теперь показывает четыре свои записи. Карточки первого варианта уточнены по `2790:1392`: высота156px, внутренние отступы12px, интервалы около18px; крипторяд занимает доступную ширину. Цветные варианты развиваются отдельно от сохранённого нейтрального макета.

Inter поставляется локально через @fontsource/inter; лицензия в `public/assets/INTER-LICENSE.txt`. Все текущие иконки заменены на пользовательский Iconity через общий компонент: [источники и правила анимации](ICONS.md). Статичные SVG — кадры тех же анимаций; Lottie загружается по наведению, без постоянных циклов. Старые Figma SVG сохранены как исходные материалы и больше не используются экранными компонентами. Временных URL ассетов в runtime нет. Исходники и отдельные сборки подготовлены для GitHub; веб-хостинг не включён.
