# OraclePay

Две версии главной страницы кошелька на React + TypeScript.

Готовые сборки находятся в [Oracle](Oracle/): [зелёная](Oracle/green/) и [оранжевая](Oracle/orange/). Общие исходники — в [frontend](frontend/).

```sh
cd frontend
npm ci
npm run dev
```

Сборка обеих версий: `npm run build:variants`. Проверки: `npm test`.

Реализованы выбор счёта, фильтрация истории, RU/EN, диалоги реквизитов и адресов, копирование. Данные вымышленные, финансовые сервисы не подключены. Переводы, пополнение и остальные страницы пока не реализованы.

Иконки предоставлены пользователем; происхождение и ограничения описаны в [ICONS.md](frontend/ICONS.md). Репозиторий не предоставляет отдельную лицензию на эти материалы.
