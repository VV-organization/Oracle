# Oracle — варианты главной

- [green](green/) — зелёная версия, счета карточками сверху.
- [orange](orange/) — оранжевая версия, счета в левой колонке.

Каждая папка содержит отдельную готовую статическую сборку. Загрузите содержимое выбранной папки на статический хостинг или запускайте через локальный HTTP-сервер. Открытие HTML через `file://` не поддерживается.

Обе версии собраны из общих исходников в `../frontend`. Не редактируйте сгенерированные файлы вручную. Пересборка: `cd frontend && npm ci && npm run build:variants` из корня репозитория.

По умолчанию русский язык; `?lang=en` включает английский. Цвет и компоновка закреплены за каждой сборкой.
